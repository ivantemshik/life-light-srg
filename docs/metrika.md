# Яндекс Метрика: подключение и цели

Код Метрики встроен в сайт (`metrika.js`) и включается номером счётчика в `config.js`. Цели отправляются из `app.js` по схеме аудита «Как отличить клик от клиента» (03.11.2026):

- **Одна цель на тип действия.** Подробности (какая кнопка, какой проект, какой вопрос) передаются параметрами из закрытого списка.
- **Без персональных данных.** Имена, телефоны, почта, адреса ссылок и текст из полей формы в Метрику не уходят.
- **Переходы не задерживаются.** Цели не мешают переходу по ссылке. Если Метрику заблокировал блокировщик рекламы, сайт работает как обычно.

## 1. Подключить счётчик

1. Создайте счётчик на [metrika.yandex.ru](https://metrika.yandex.ru) **на аккаунте компании** (подрядчику выдаётся гостевой доступ «Редактирование», не «Представитель»).
   - Адрес сайта: без `https://` и `www`.
   - Часовой пояс: Москва.
   - Валюта: рубль.
2. До тестов включите фильтры:
   - «Не учитывать мои визиты»;
   - IP-адрес офиса.

   «Фильтровать роботов по поведению» не включайте: это необратимо.
3. Впишите номер счётчика в `config.js`. Там же три настройки:

```js
metrikaId: 12345678,
metrikaWebvisor: false,        // Вебвизор: включать только после решения владельца и юриста
siteVersion: '2026-11_v2',     // версия сайта, менять при каждой заметной правке
telegram: 'https://t.me/lifelightlife',      // чат для переписки (кнопка «Обсудить в Telegram»)
telegramTargetType: 'personal',             // куда ведёт эта ссылка: personal, bot, business_link
telegramChannel: 'https://t.me/LifeLight_ru' // канал с работами
```

4. Задеплойте сайт. Счётчик загрузится сам.

Сайт включает счётчик с такими настройками:

| Настройка | Значение | Зачем |
|---|---|---|
| `clickmap` | да | Карта кликов |
| `trackLinks` | да | Внешние ссылки и автоцель «Переход в мессенджер» |
| `accurateTrackBounce` | да | Точный показатель отказов |
| `webvisor` | из `config.js`, сейчас нет | Решение владельца и юриста |
| `trackHash` | нет | Переходы по пунктам меню не считаются отдельными просмотрами |
| `ecommerce` | нет | Корзины нет |
| `sendTitle` | да | Заголовок страницы без личных данных |
| `params.site_version` | из `config.js` | Сравнение периодов до и после правок сайта |

## 2. Создать цели

**Цели → Добавить цель → «JavaScript-событие»**, условие «совпадает», идентификатор точно как в таблице.

Параметры попадают в отчёт «Параметры событий», только если для идентификатора создана своя цель. Поэтому создайте все цели из таблиц.

Ценность целям не назначайте. В рекламных кампаниях оптимизацию по этим целям не включайте.

## 4. Проверка

1. Откройте сайт с `?_ym_debug=2&utm_campaign=qa_test`. Режим отладки тоже отправляет данные, а метка `qa_test` позволяет отделить тестовые визиты сегментом.
2. В панели отладки (вкладки Console и Events) проверьте:
   - **просмотр страницы:** при загрузке ровно один `PageView`, при переходах по меню и открытии окон новых нет;
   - **клик по Telegram, почте, кнопкам расчёта:** ровно одна цель с нужными параметрами;
   - **окна проектов и услуг, вопросы:** одна цель на открытие, закрытие ничего не отправляет;
   - **блоки:** при прокрутке каждый засчитывается один раз за визит;
   - **параметры:** только значения из словаря, без адресов и личных данных.
3. Повторите на телефоне (Safari на iPhone, Chrome на Android) и при открытии сайта из Telegram.
4. Через 10–15 минут сверьте отчёт «Конверсии» с тем, что нажимали.

## 5. Статистика в Telegram-боте

Команды `/stats` и `/metrika` и ежедневный отчёт показывают:

- визиты, посетителей, отказы, глубину и время на сайте;
- число заявок и конверсию по Метрике;
- источники трафика.

На хостинге reg.ru номер счётчика и цели записаны в `~/life-light-data/config.php` (`metrika_counter_id`, `metrika_lead_goal_id`), токен лежит отдельным файлом `~/life-light-data/metrika_token.txt`. Для Node.js-сервера (`server/`) нужны три значения в `server/.env`:

- `METRIKA_COUNTER_ID`: номер счётчика.
- `METRIKA_TOKEN`: OAuth-токен с правом чтения статистики. Как получить:
  1. На [oauth.yandex.ru](https://oauth.yandex.ru) нажмите «Создать приложение».
  2. Платформа «Веб-сервисы», Redirect URI `https://oauth.yandex.ru/verification_code`, доступ «Яндекс Метрика: получение статистики» (`metrika:read`).
  3. Откройте `https://oauth.yandex.ru/authorize?response_type=token&client_id=<ID приложения>` под аккаунтом, у которого есть доступ к счётчику, и скопируйте токен.
- `METRIKA_LEAD_GOAL_ID`: числовой номер цели `lead_sent` (виден в списке целей счётчика).

## 6. Связь заявок с Метрикой

Каждая заявка хранит ClientID посетителя из Метрики (`ym_client_id`) и UTM-метки первого захода. ClientID показан в карточке заявки в боте и есть отдельной колонкой в выгрузке `/export`. По нему статусы «Смета», «Договор» можно загрузить обратно в Метрику как офлайн-конверсии.
