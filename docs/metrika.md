# Яндекс Метрика: подключение и цели

Код Метрики уже встроен в сайт (`metrika.js`) и включается одной настройкой. 20 целей отправляются из `app.js`.

## 1. Подключить счётчик

1. Создайте счётчик на [metrika.yandex.ru](https://metrika.yandex.ru): адрес сайта, часовой пояс Москва, включите **Вебвизор, карту скроллинга, аналитику форм**.
2. Скопируйте номер счётчика и впишите его в `config.js`:

```js
metrikaId: 12345678,
```

3. Задеплойте сайт. Больше ничего в коде менять не нужно: счётчик загрузится сам, цели начнут приходить.

## 2. Создать цели

В счётчике: **Цели → Добавить цель → тип «JavaScript-событие»**, идентификатор пишется точно как в таблице. Главная конверсия: `lead_sent`.

| Идентификатор | Название цели в Метрике | Когда срабатывает |
|---|---|---|
| `lead_sent` | Заявка отправлена (главная) | Сервер принял заявку и выдал её номер |
| `form_submit` | Нажали «Получить расчёт» | Поля заполнены верно, заявка уходит на сервер |
| `form_start` | Начали заполнять форму | Первый фокус в любом поле формы |
| `form_invalid` | Ошибка заполнения | Отправка с незаполненными или неверными полями |
| `lead_error` | Заявка не дошла | Сервер не ответил или отклонил заявку |
| `photo_attached` | Приложили фото | Добавлено хотя бы одно фото (параметр `count`) |
| `click_telegram` | Клик на Telegram | Любая ссылка на t.me (параметр `place`: раздел страницы) |
| `click_email` | Клик на почту | Ссылка mailto |
| `click_phone` | Клик на телефон | Ссылка tel, когда телефон появится на сайте |
| `cta_hero` | Кнопка на первом экране | «Рассчитать по фото» на первом экране |
| `cta_segment_home` | Расчёт для дома | Кнопка в карточке «Частным домам» |
| `cta_segment_business` | Расчёт для бизнеса | Кнопка в карточке «Бизнесу и ТЦ» |
| `cta_case` | «Хочу так же» | Кнопка в кейсе |
| `cta_newyear` | Новогодний дизайн | «Получить 3 варианта дизайна» |
| `cta_price` | Расчёт из блока цен | «Рассчитать по фото» в блоке «Сколько стоит подсветка» |
| `cta_project` | Похожий проект | Кнопка в окне проекта |
| `cta_service` | Расчёт из услуги | Кнопка в окне «Что входит в работу» |
| `open_project` | Открыли проект | Фото проекта открыто крупно (параметр `project`) |
| `open_case` | Открыли кейс | Переключили вкладку кейса (параметр `case`) |
| `compare_slider` | Сравнили до и после | Сдвинули ползунок в первом кейсе |

Рекомендуемая сводная цель **«Обращение»**: тип «JavaScript-событие», три условия «идентификатор совпадает» с `lead_sent`, `click_telegram`, `click_email`. Она срабатывает на любое из них и показывает все обращения, включая уход в мессенджер.

Воронка формы: `form_start` → `form_submit` → `lead_sent`. Разница между шагами показывает, где люди бросают заявку.

## 3. Статистика в Telegram-боте

Команды `/stats` и `/metrika` и ежедневный отчёт показывают визиты, посетителей, отказы, глубину, время на сайте, число заявок и конверсию по Метрике, а также источники трафика. Для этого серверу нужны три значения в `server/.env`:

- `METRIKA_COUNTER_ID`: номер счётчика.
- `METRIKA_TOKEN`: OAuth-токен с правом чтения статистики. Получение: [oauth.yandex.ru](https://oauth.yandex.ru) → «Создать приложение» → платформа «Веб-сервисы», Redirect URI `https://oauth.yandex.ru/verification_code`, доступ «Яндекс Метрика: получение статистики» (`metrika:read`). Затем откройте `https://oauth.yandex.ru/authorize?response_type=token&client_id=<ID приложения>` под аккаунтом, у которого есть доступ к счётчику, и скопируйте токен.
- `METRIKA_LEAD_GOAL_ID`: числовой номер цели `lead_sent` (виден в списке целей счётчика).

## 4. Связь заявок с Метрикой

Каждая заявка хранит ClientID посетителя из Метрики (`ym_client_id`) и UTM-метки первого захода. В боте ClientID показан в карточке заявки, в выгрузке `/export` он есть отдельной колонкой. По нему можно найти визит в Вебвизоре или загрузить офлайн-конверсии (например, «Договор») обратно в Метрику.
