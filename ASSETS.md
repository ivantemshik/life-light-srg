# Визуальные материалы

Первый экран, архитектурный эскиз и иллюстративные блоки сгенерированы встроенным инструментом imagegen. Canva-проект `DAHZqlG2HKA` изучен через Canva connector: изображения в нём — небольшие растровые фрагменты PNG-макета. Для качества на современных экранах они воссозданы отдельными визуальными материалами. В блоке «Наши проекты» по последнему запросу используются оригинальные фотографии компании.

| Файл в assets | Назначение |
|---|---|
| `hero.webp` | Дом, контурная подсветка, сад и ступени; первый экран и частный дом |
| `garden.webp` | Ландшафт, освещение деревьев и ступеней |
| `restaurant.webp` | Ресторанная терраса, свет для бизнеса |
| `facade.webp` | Архитектурная подсветка коммерческого фасада |
| `sketch.webp` | Архитектурная визуализация на белом фоне |
| `spotlight.webp` | Архитектурный настенный светильник |
| `groundlight.webp` | Грунтовый светильник с защитой от погоды |
| `installation.webp` | Монтаж фасадного светильника |
| `*-small.webp` | Миниатюры сгенерированных фотографий для трёх показателей |

Точные финальные промпты: `docs/generation-prompts.json`. Способ: built-in imagegen, без API-ключа. Итоговые WebP находятся внутри проекта; сайт не зависит от временных ссылок Canva или путей `.codex/generated_images`.

Manrope: Google Fonts, локальные TTF 400 / 500 / 600. Лицензия SIL Open Font License 1.1 сохранена в `assets/OFL-Manrope.txt`.
