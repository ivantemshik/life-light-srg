# Жизнь — Свет

Адаптивный лендинг компании по архитектурной, декоративной и новогодней подсветке (Москва и Московская область), сервер заявок с базой на российском сервере, Telegram-бот для обработки заявок и Яндекс Метрика с целями.

Сайт: чистые HTML, CSS и JavaScript без сборки. Сервер: Node.js 24 без внешних npm-пакетов (база на встроенном `node:sqlite`).

**Исходный сайт:** https://life-light-architecture.vercel.app/

**Эта ветка (временная публикация):** https://life-light-tz.vercel.app/

**Рабочий сайт:** https://жизньсвет.рф (хостинг reg.ru, выкладка: `sh deploy/regru-upload.sh`, подробности в [docs/deploy.md](docs/deploy.md)).

## Быстрый старт

```sh
npm run dev      # только сайт: http://127.0.0.1:4173
npm start        # сайт + API заявок + бот: http://127.0.0.1:8080 (настройки в server/.env)
npm run check    # синтаксис всех скриптов
npm test         # тесты сервера, бота, прокси и Метрики
```

## Что сделано по ТЗ

Дизайн сайта сохранён: новые блоки собраны из его же элементов (светлые и тёмные карточки, серые панели, кнопки-пилюли, те же размеры и скругления).

**Светлая и тёмная тема.** Переключатель в углу фото первого экрана, на телефоне в шапке рядом с меню. Выбор запоминается; пока посетитель не выбрал, тема следует настройке устройства. В тёмной теме на первом экране мерцают звёзды, эскиз в блоке «О нас» заменяется ночным рисунком (`assets/sketch-night-drawn.webp`, сделан в ChatGPT, чёрный фон убран, чтобы рисунок сливался с тёмной темой).

- [x] **Тексты под целевую аудиторию** (по исследованию ЦА). Слова клиента вместо языка подрядчика: «подсветка дома и участка», а не «архитектурная подсветка». Тексты отвечают на главные сомнения: сколько стоит, выдержит ли мороз, не повредят ли фасад, кто работает на высоте, кто снимет новогодний декор. Убрано «работаем с 2018 года» (см. ниже), вместо него «ответ на заявку за 1 час».
- [x] **Новые блоки, полноценный лендинг.**
  - «Что подсвечиваем»: частным домам и бизнесу с ТЦ, все 8 услуг из материалов компании.
  - «Что меняет подсветка»: один и тот же загородный дом без подсветки и с ней, ползунок сравнения; ниже зоны, оборудование и свет.
  - «Сколько стоит подсветка»: что влияет на цену и условия (смета бесплатно, цена в договоре, оплата по факту, гарантия 36 месяцев).
  - «Рассчитаем подсветку по фото»: форма заявки.
  - В вопросах новые ответы про цену, мороз, фасад и демонтаж.
- [x] **Фото объектов и кейсы.** «Наши проекты»: 12 реальных объектов, у большинства несколько фото. В окне проекта описание, зоны и оборудование, фото открывается на весь экран с увеличением.
- [x] **Форма заявок → БД на российском сервере → Telegram-бот.** Форма: тип объекта, до 5 фото (сжимаются в браузере), имя, контакт и комментарий. Кнопки в блоках заранее отмечают нужные ответы. Заявка с UTM-метками и ClientID Метрики сохраняется в SQLite, менеджерам приходит карточка с фото и кнопками статусов, срочные помечены. Статистика заявок и показатели Метрики в боте (`/stats`, ежедневный отчёт), выгрузка в Excel (`/export`). На жизньсвет.рф работает PHP-версия (`api/`, бот сам забирает сообщения из Telegram по cron), для своего сервера есть Node.js-версия (`server/`). Пошагово: [docs/deploy.md](docs/deploy.md).
- [x] **Яндекс Метрика и цели.** Счётчик включается номером в `config.js`. Счётчик 114059448 подключён, 23 цели созданы. Цели и параметры сделаны по аудиту Метрики: клики по Telegram и почте, кнопки к расчёту, заявки из формы, открытия проектов, услуг и вопросов, просмотры блоков; личные данные в Метрику не уходят. Инструкция: [docs/metrika.md](docs/metrika.md).

Счётчик Метрики передан владельцу (septleaderonline@yandex.ru). Что нужно от заказчика: для полностью надёжной связи с Telegram — бесплатный аккаунт Cloudflare (прокси из папки `worker/`).

## Файлы проекта

| Файл | Назначение |
|---|---|
| `index.html` | Контент, SEO, разделы страницы и форма |
| `config.js` | Настройки: адрес API заявок, номер счётчика Метрики, Telegram |
| `style.css` | Вёрстка и стили десктопа; новые блоки в конце файла |
| `mobile.css` | Телефоны и планшеты; новые блоки в конце файла |
| `app.js` | Меню, тема, карусель и окна проектов, просмотр фото, услуги, ползунок «до и после», форма с фото, цели Метрики |
| `metrika.js` | Код счётчика Яндекс Метрики и функция целей |
| `api/` | Сервер заявок на PHP для хостинга reg.ru: форма, SQLite, бот (polling из cron каждую минуту), задание по расписанию |
| `server/` | Тот же сервер заявок на Node.js для своего сервера (VPS) |
| `worker/` | Cloudflare Worker: прокси до Telegram Bot API |
| `deploy/` | systemd и nginx для российского сервера |
| `test/` | Автотесты (`npm test`) |
| `assets/` | Фотографии и шрифты |
| `docs/` | Отчёт о компании, Метрика, развёртывание, источники фотографий |

## Изменение контента

- Тексты и разделы: `index.html`.
- Проекты в галерее: массив `projects` в `app.js` (индекс `data-project` карточки должен совпадать с позицией в массиве).
- Тексты окон «Что входит в работу»: массив `services` в `app.js`.
- «Что меняет подсветка»: блок `#before-after` в `index.html`, фото `project-country-house.webp` и `project-country-house-unlit.webp`.
- Адрес API и номер Метрики: `config.js`.
- Цвета обеих тем: блок «Светлая и тёмная тема» в конце `style.css` (светлые значения в `:root`, тёмные в `:root[data-theme="dark"]`).

## Размещение

Рекомендуется всё на российском сервере: сервер сам раздаёт сайт (`SERVE_STATIC=1`), форма шлёт заявки на тот же домен. Возможен вариант «сайт на Vercel, API на сервере»: [docs/deploy.md](docs/deploy.md), раздел 4. Пока API не подключён, форма на Vercel честно сообщает, что заявка не отправлена, и предлагает Telegram. `.vercelignore` исключает сервер, прокси, тесты и документацию из публикации.

## Что проверить с заказчиком

- **Телефон.** +7 985 928-37-99 (подтвердил владелец) стоит в блоке контактов и подвале; клики учитываются целью `phone_click`.
- **«Работаем с 2018 года»** убрано: по ОГРН юрлицо зарегистрировано в 2024 году, исследование ЦА отмечает это как риск доверия. Если опыт с 2018 года подтверждается (бренд или команда), можно вернуть с пояснением.
- **Проекты.** Описаны только по тому, что видно на фото. Для полноценных кейсов нужны район, срок монтажа и отзыв владельца с разрешением на публикацию.
- **Фото.** Часть снимков портфолио 800 px по ширине (например, `project-contour`); оригиналы с телефона улучшат галерею. Папка `media/life-light/` из отчёта о компании пока не передана.
- **Снимок «без подсветки»** в блоке «Что меняет подсветка» (`assets/project-country-house-unlit.webp`) сделан в ChatGPT из реального фото: гирлянды и светильники убраны, кадр совпадает с оригиналом. Если есть настоящее фото этого дома до монтажа, лучше заменить.
- **Фото для блока «Бизнесу и ТЦ»** (`assets/facade.webp`) сгенерировано, как и первый экран; стоит заменить снимком реального коммерческого объекта.
- **Неон в вывесках в Москве.** По правилам размещения вывесок (902-ПП) неон и мерцающие элементы ограничены; формулировку услуги для бизнеса стоит сверить.
- **Telegram.** Канал @LifeLight_ru указан в контактах и подвале. Кнопка «Обсудить в Telegram» и ссылки в сообщениях формы тоже ведут на канал; если для переписки есть аккаунт менеджера, их лучше вести на него (`config.js`, поле `telegram`, и кнопка в блоке контактов).
- **Идентификация на reg.ru.** Хостинг и домен жизньсвет.рф требуют идентификации владельца (паспортные данные); без неё reg.ru может приостановить услуги.
- **Политика конфиденциальности и cookie** по ссылкам на life-light.ru должны упоминать сбор данных через форму и Яндекс Метрику.
