# Жизнь — Свет

Адаптивный лендинг компании по архитектурной, декоративной и новогодней подсветке (Москва и Московская область), сервер заявок с базой на российском сервере, Telegram-бот для обработки заявок и Яндекс Метрика с целями.

Сайт: чистые HTML, CSS и JavaScript без сборки. Сервер: Node.js 24 без внешних npm-пакетов (база на встроенном `node:sqlite`).

**Опубликованный сайт:** https://life-light-architecture.vercel.app/

## Быстрый старт

```sh
npm run dev      # только сайт: http://127.0.0.1:4173
npm start        # сайт + API заявок + бот: http://127.0.0.1:8080 (настройки в server/.env)
npm run check    # синтаксис всех скриптов
npm test         # тесты сервера, бота, прокси и Метрики
```

## Что сделано по ТЗ

Дизайн сайта сохранён: новые блоки собраны из его же элементов (светлые и тёмные карточки, серые панели, кнопки-пилюли, те же размеры и скругления).

**Светлая и тёмная тема.** Переключатель в углу фото первого экрана, на телефоне в шапке рядом с меню. Выбор запоминается; пока посетитель не выбрал, тема следует настройке устройства. В тёмной теме на первом экране мерцают звёзды, эскиз в блоке «О нас» заменяется ночной версией (`assets/sketch-night.webp`).

- [x] **Тексты под целевую аудиторию** (по исследованию ЦА). Слова клиента вместо языка подрядчика: «подсветка дома и участка», а не «архитектурная подсветка». Тексты отвечают на главные сомнения: сколько стоит, выдержит ли мороз, не повредят ли фасад, кто работает на высоте, кто снимет новогодний декор. Убрано «работаем с 2018 года» (см. ниже), вместо него «ответ на заявку за 1 час».
- [x] **Новые блоки, полноценный лендинг.**
  - «Что подсвечиваем»: частным домам и бизнесу с ТЦ, все 8 услуг из материалов компании.
  - «Кейсы»: три объекта с зонами, оборудованием и светом; в первом ползунок «без подсветки / с подсветкой».
  - «Новогоднее оформление под ключ»: 3 варианта дизайна, гирлянды и фигуры, аренда декора с демонтажем, монтаж за 24 часа, отсчёт дней до Нового года.
  - «Сколько стоит подсветка»: что влияет на цену и условия (смета бесплатно, цена в договоре, оплата по факту, гарантия 36 месяцев).
  - «Рассчитаем подсветку по фото»: форма заявки.
  - В вопросах новые ответы про цену, мороз, фасад и демонтаж.
- [x] **Фото объектов и кейсы.** Описания проектов в галерее расширены, кейсы собраны по реальным фото компании.
- [x] **Форма заявок → БД на российском сервере → Telegram-бот через Cloudflare Worker.** Форма: тип объекта, зоны, сроки, до 5 фото (сжимаются в браузере), имя и контакт. Кнопки в блоках заранее отмечают нужные ответы. Заявка с UTM-метками и ClientID Метрики сохраняется в SQLite, менеджерам приходит карточка с фото и кнопками статусов, срочные помечены. Статистика заявок и показатели Метрики в боте (`/stats`, ежедневный отчёт), выгрузка в Excel (`/export`). Пошагово: [docs/deploy.md](docs/deploy.md).
- [x] **Яндекс Метрика и цели.** Счётчик включается номером в `config.js`, 20 целей уже отправляются. Инструкция: [docs/metrika.md](docs/metrika.md).

Что нужно от заказчика для запуска: номер счётчика Метрики, токен бота, VPS в РФ, аккаунт Cloudflare.

## Изменение контента

- Тексты и разделы: `index.html`.
- Проекты в галерее: массив `projects` в `app.js` (индекс `data-project` карточки должен совпадать с позицией в массиве).
- Тексты окон «Что входит в работу»: массив `services` в `app.js`.
- Кейсы: блок `#cases` в `index.html`.
- Адрес API и номер Метрики: `config.js`.
- Цвета обеих тем: блок «Светлая и тёмная тема» в конце `style.css` (светлые значения в `:root`, тёмные в `:root[data-theme="dark"]`).

## Размещение

Рекомендуется всё на российском сервере: сервер сам раздаёт сайт (`SERVE_STATIC=1`), форма шлёт заявки на тот же домен. Возможен вариант «сайт на Vercel, API на сервере»: [docs/deploy.md](docs/deploy.md), раздел 4. Пока API не подключён, форма на Vercel честно сообщает, что заявка не отправлена, и предлагает Telegram. `.vercelignore` исключает сервер, прокси, тесты и документацию из публикации.

## Что проверить с заказчиком

- **Телефон.** На сайте компании разные номера, поэтому телефона на странице нет. После подтверждения его можно добавить (ссылки `tel:` уже учитываются целью `click_phone`).
- **«Работаем с 2018 года»** убрано: по ОГРН юрлицо зарегистрировано в 2024 году, исследование ЦА отмечает это как риск доверия. Если опыт с 2018 года подтверждается (бренд или команда), можно вернуть с пояснением.
- **Кейсы.** Описаны только по тому, что видно на фото. Для полноценных кейсов нужны район, срок монтажа и отзыв владельца с разрешением на публикацию.
- **Фото.** Большинство снимков портфолио 800 px по ширине; оригиналы с телефона улучшат галерею. Папка `media/life-light/` из отчёта о компании пока не передана.
- **Снимок «без подсветки»** в блоке «Что меняет подсветка» (`assets/project-country-house-unlit.webp`) сделан в ChatGPT из реального фото: гирлянды и светильники убраны, кадр совпадает с оригиналом. Если есть настоящее фото этого дома до монтажа, лучше заменить.
- **Фото для блока «Бизнесу и ТЦ»** (`assets/facade.webp`) сгенерировано, как и первый экран; стоит заменить снимком реального коммерческого объекта.
- **Неон в вывесках в Москве.** По правилам размещения вывесок (902-ПП) неон и мерцающие элементы ограничены; формулировку услуги для бизнеса стоит сверить.
- **Политика конфиденциальности и cookie** по ссылкам на life-light.ru должны упоминать сбор данных через форму и Яндекс Метрику.
