# Жизнь — Свет

Адаптивный лендинг компании по архитектурному и декоративному освещению. Чистые HTML, CSS и JavaScript, без фреймворка, внешних зависимостей и этапа сборки.

**Опубликованный сайт:** https://life-light-architecture.vercel.app/

## Локальный запуск

Требуется Node.js 24 LTS или новее. Установка npm-пакетов не требуется.

```sh
npm run dev
```

Откройте http://127.0.0.1:4173. Остановка сервера: Ctrl+C.

```sh
npm run check
```

Команда проверяет синтаксис JavaScript приложения и локального сервера.

## Файлы проекта

| Файл | Назначение |
|---|---|
| index.html | Контент, SEO, секции страницы и карточки проектов |
| style.css | Основная вёрстка, типографика и стили десктопа |
| mobile.css | Адаптация телефонов и планшетов |
| app.js | Меню, галерея, карусель и описания услуг |
| assets/ | Локальные фотографии, иллюстрации и шрифты |
| server.mjs | Сервер для локального предпросмотра |
| vercel.json | Статическое размещение и HTTP-заголовки |
| ASSETS.md | Происхождение изображений и лицензия шрифта |
| docs/ | Отчёт о компании, референс, источники фотографий и промпты |

В проекте нет бэкенда, базы данных, аналитики и сбора заявок. Кнопки связи ведут в Telegram и почтовую программу. Все нужные для работы сайта изображения и шрифты находятся в репозитории; временные пути и ссылки Canva не используются приложением.

## Изменение контента

- Тексты, ссылки и карточки на странице: index.html.
- Названия, изображения и описания объектов в галерее: массив projects в app.js. Индекс data-project карточки в HTML должен соответствовать её позиции в массиве.
- Состав услуг и тексты модальных окон: массив services в app.js.
- Фотографии: файлы в assets/; при замене обновите src, alt и размеры изображений.

Контакты: Telegram LifeLight_ru, email info@life-light.ru. Перед передачей заказчику сверьте актуальность реквизитов и контактов. Телефоны не размещены из-за расхождений в исходном отчёте.

## Размещение на Vercel

1. Импортируйте этот GitHub-репозиторий в аккаунт заказчика на Vercel.
2. Выберите Framework Preset: Other, корень проекта — корень репозитория.
3. Этапы Install и Build не требуются. Каталог публикации — точка (.). Настройки заданы в vercel.json.
4. Нажмите Deploy. При подключённом GitHub последующие push в main будут запускать деплой.

Альтернатива через Vercel CLI:

```sh
npx vercel login
npx vercel --prod
```

Переменные окружения и API-ключи не нужны. Привязка .vercel/ к текущему аккаунту в репозиторий не входит. Создание репозитория не переносит существующий Vercel-проект или домен: для передачи заказчику импортируйте репозиторий в его аккаунт либо отдельно передайте существующий проект средствами Vercel.

.vercelignore исключает документацию, исходный референс и локальные служебные файлы из публикации. GitHub Actions проверяет синтаксис JavaScript при push и pull request.
